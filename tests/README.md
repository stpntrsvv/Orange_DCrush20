# Проверки

Rust-тесты встроены в `firmware/orange-dsp`; численные fixtures и текстовые
эталоны находятся в `simulation/experiments/`. Python-проверки — `simulation/`.
Отдельной копии тестов в этом каталоге нет.

[Установка и команды](../docs/REPOSITORY.md),
[текущие ограничения точности](../docs/STATUS.md).
При публикации 2026-10-06 прошли 53 release-теста, включая диагностические.
Это проверка программного состава, не аттестация полного аудиотракта.
