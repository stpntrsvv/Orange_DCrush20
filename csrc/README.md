# Низкоуровневая граница

DSP и управление контроллером переносятся в Rust `no_std`. C-драйверы, startup,
HAL, LL и Cube runtime запрещены. Здесь могут лежать лишь отдельно проверяемые
CMSIS-DSP объекты/ABI, если они дадут измеримый выигрыш. Предвычисление линейной
подсистемы выполняется вне аудиоцикла.
