# Тяжёлые результаты вне Git

Исходники, схемы, отчёты, JSON-метрики, текстовые эталоны и журналы находятся
в обычном Git. Аудио, бинарные траектории/памяти, PCM/NPZ и точные ELF
сохранённых проб опубликованы отдельным проверенным архивом:
[снимок results-2026-10-06](https://github.com/stpntrsvv/Orange_DCrush20/releases/tag/results-2026-10-06).
Последние измерения в снимке — 2026-09-30, дата публикации — 2026-10-06.

`source_manifest.json` содержит путь, исходный размер и SHA-256 каждого файла.
`github_release_assets.json` фиксирует размеры и SHA-256 всех десяти файлов
на стороне GitHub; они совпали с локальными оригиналами.
В архиве сохранены прежние пути. Совпадающее содержимое упаковано один раз,
остальные пути представлены tar hardlink; это не объединение измерительных
серий. При восстановлении каждый путь снова содержит исходные байты.
Кэши `target/`, `.venv/`, `.git/`, `__pycache__/`, `tmp/` не архивируются.
Локальные оригиналы результатов при публикации не удалялись.

## Восстановление

Нужны `gh`, `zstd` и `tar`. Из корня клонированного репозитория:

```sh
mkdir -p .artifacts/download
cd .artifacts/download
gh release download results-2026-10-06 --repo stpntrsvv/Orange_DCrush20
shasum -a 256 -c SHA256SUMS
cat orange-results-2026-10-06.tar.zst.part* | zstd -dc | tar -xf - -C ../..
cd ../..
```

Части объединяются в лексикографическом порядке `.part001`, `.part002`, …;
каждая не больше 1 ГиБ. Восстанавливать в свежий клон: извлечение записывает
архивные результаты по исходным путям. Не извлекать поверх новых локальных
серий. Архив содержит собственный `artifacts/source_manifest.json`;
его контрольная сумма также записана в `release_manifest.json` релиза.

Для полной проверки скачанного архива без извлечения:

```sh
python3 tools/export_artifacts.py --out .artifacts/download --verify
```

Команда проверяет части, каждый файл/ссылку tar, размеры и SHA-256.
Для проверки восстановленного локального снимка:

```sh
python3 tools/check_repository.py --artifacts
```

## Повторный экспорт

Из полного локального проекта, в **новый** каталог, нужен `zstd` в PATH:

```sh
python3 tools/export_artifacts.py --out /tmp/orange-results-new
python3 tools/export_artifacts.py --out /tmp/orange-results-new --verify
```

Этот экспортёр предназначен для исходного снимка 2026-10-06; для будущего
датированного релиза сначала обновить его дату/имя. Экспорт не запускает
моделирование и не меняет результаты. Сборочные кэши и пользовательские
настройки остаются локальными; их воспроизводят инструментами из исходников.
