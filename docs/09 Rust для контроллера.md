# Rust для STM32H7R3

Основное DSP-ядро — Rust `no_std`, `bounded48::BoundedState<3,7>`, BDF2/48.
Аппаратные RAM-стенды используют CMSIS и прямые регистры, без HAL/LL/PAC,
Embassy и Cube runtime. Flash не писать; после каждой пробы `reset run`
и проверка штатного приложения/fault-регистров.

[Код, сборка и действующие проверки](../firmware/README.md),
[установка и ограничения переносимости](REPOSITORY.md),
[непрерывный аудиотракт](13%20Аудиотракт%20DMA%20и%20силовой%20выход.md).

`orange-render` и старые решатели 96 кГц — история/сравнение.
Нынешний `h7r3-runtime` содержит измерительные стенды, не завершённую
ADC/DMA/PWM-аудиопрошивку. Их наличие не означает готовый звук.
[История переноса и оптимизаций](history/09%20История%20переноса%20Rust.md).
