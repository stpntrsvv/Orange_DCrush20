# Архитектура и бюджет

Актуализировано 2026-10-06. Рабочая база — `bounded48::BoundedState<3,7>`,
BDF2/48 кГц, один шаг на выход, до трёх попыток на причинный блок,
ранний выход, физические законы и обе собственные памяти сохранены.
Восемь физических портовых координат, блоки 1/1/2/3/1, два слоя памяти по 28.

Полная MNA f64/f32 остаётся эталоном; линейные неизвестные точно исключены,
коэффициенты подготовлены вне аудиоцикла. Общий глобальный Newton/LU
не является архитектурой прошивки. Основной TDA-вариант сохраняет побитово
траекторию принятой базы на полной гитаре; IC3A noise-старт остаётся опытом.

600 МГц / 48 кГц = 12500 тактов **всего** CPU на выходной отсчёт.
Среднее ядра на полной гитаре — 8673/8878/9229 тактов для 100/250/1000 мВ.
Все измеренные окна 64 проходят 12500, отдельные отсчёты могут быть дороже.
Худшее окно 12417,8 оставляет около 5261 такта на целый блок 64 для I/O,
прерываний и подготовки выхода. Полный непрерывный тракт ещё не измерен.

Первый оконечник — LM1875, класс AB; выход TIM1/PWM/DMA с реконструкцией
рассматривается для первого прототипа. Class-D-порт и кабинет/FIR из прежнего
плана не являются текущим заданием. Реальные `v/i` пока не включены в ядро.
