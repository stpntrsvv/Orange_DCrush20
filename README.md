# Orange_DCrush20

Физическая схемная модель Orange Crush 20L для STM32H7R3. Сохраняются
схемные нелинейности, обратные связи и динамическая память. Python
содержит численный эталон; Rust `no_std` — исполнение на контроллере.
Источник — сторонняя схема `Orange Crush 20 L`, 2012.04.15,
пока не сверенная с конкретным усилителем.

Документация приведена в порядок **2026-10-06**. Последние сохранённые
аппаратные измерения — **2026-09-30**; новых измерений при публикации нет.

## Принятая структура

Рабочее ядро — `bounded48::BoundedState<3,7>`: BDF2, 48 кГц, один шаг
на выходной отсчёт, до трёх попыток на причинный блок с ранним выходом.
Сохраняются физические законы и оба слоя собственной памяти. LUT,
дополнительные адаптивные итерации, поиск длины и временные подшаги запрещены.
Архитектура принята 2026-09-28; основной вариант включает полировку TDA
от 2026-09-29. Старые варианты 96 кГц служат для сравнения и истории.

Среднее время основного ядра на H7R3/600 МГц: **8673 / 8878 / 9229 тактов**
на полной гитаре с пиком 100 / 250 / 1000 мВ. Все измеренные окна 64
отсчёта укладываются в 12500 тактов на выход. Это измерение ядра;
**непрерывный аудиотракт с ADC/DMA и физическим выходом ещё не проверен**.
Сильный шум имеет отдельные численные ограничения, описанные в STATUS.

Первый выбранный оконечник — имеющаяся LM1875 с одним источником 24 В.
Рассматривается выход TIM1/PWM через DMA и аналоговый фильтр. Сборка,
пины, входная обвязка и измерительный тракт ещё не подтверждены.
Кабинет на MCU сейчас не нужен по последнему решению пользователя.
Измерения динамика пока планируются как телеметрия; цифровой контур не замкнут.

## Быстрая проверка

Из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
python3 tools/check_repository.py
cd firmware
cargo test -p orange-dsp --lib --release --target aarch64-apple-darwin --features noise48-candidate
```

Последняя команда проверена на Apple Silicon; установленный Rust должен
быть доступен в `PATH`. Настройка целевой платформы и аппаратная сборка —
в [инструкции](docs/REPOSITORY.md). `ngspice` нужен для независимых
схемных проверок. Работа с платой всегда завершается `reset run`;
запись flash не разрешена.

В Git находятся исходники, документы, схемы, отчёты, JSON-метрики,
текстовые эталоны и журналы. Тяжёлые траектории, аудио и исполнявшиеся
ELF находятся в [GitHub Releases](https://github.com/stpntrsvv/Orange_DCrush20/releases).
Они восстанавливаются по прежним путям; [инструкция и SHA-256](artifacts/README.md).
Кэши сборки, виртуальное окружение и временные файлы не публикуются.
