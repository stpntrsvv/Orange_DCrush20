# История создания вариантов

Здесь находятся восемь одноразовых скриптов, которые создавали или
переписывали прежние варианты Rust-ядра. Они вынесены из каталога модели
2026-10-06; вычисление корня проекта исправлено с `parents[1]` на `parents[2]`.
Сохранённые копии в снимках опытов не менялись.

`implement_*`, `add_bounded_halley.py` и `instrument_repeated.py` не являются
регенераторами нынешнего `bounded48.rs`. Их запуск пишет в рабочие исходники
и может восстановить исторический вариант. Они оставлены для изучения
происхождения изменений, а не для штатного запуска или проверки проекта.

Действующий генератор только 48-кГц коэффициентов:
`../generate_rate48_coefficients.py --out НОВЫЙ_КАТАЛОГ`.
Модели, анализаторы, подготовка опытов и действующие проверки остаются
в `simulation/`, их пути и импорты сохранены.
