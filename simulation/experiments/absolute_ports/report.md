# Абсолютные порты: отрицательный опыт с 29 координатами

Дата: 2026-09-26. Кандидат `absolute-ports` **не принят** и не заменяет
`physical-fpu`. Сырые аппаратные результаты сохранены в `metrics.json`.

Линейная часть BDF2 при 96 кГц исключена заранее в f64. На шаге вычисляется
линейная предыстория, далее решается `q - qL + H phi(q) = 0` с 29 сохранёнными
MNA-координатами и 14 нелинейными воздействиями. В конце восстанавливаются
27 исключённых координат и проверяются все 56 исходных уравнений.
Нелинейные законы, два шага Newton и восемь проб поиска шага сохранены.

## Измерения

Парная RAM-проба STM32H7R3: 1024 шага, первые 32 исключены из времени.
В контрольном пути — отложенные производные, FPU-корни и CORDIC-экспоненты.

| Вход | 29 координат с защитой, тактов/шаг | Рабочий путь | Отказы нового / рабочего |
|---|---:|---:|---:|
| Треугольник 250 Гц, 100 мВ | 25 792 | 13 472 | 1 / 0 |
| Тот же, 1 В | 62 001 | 28 834 | 706 / 695 |
| Резкий псевдослучайный шум, 250 мВ | 74 637 | 36 013 | 992 / 992 |

Защита дополнительно контролирует дефект портового уравнения в масштабах
состояния. Без неё прежняя нормированная невязка не гарантировала точность:
на независимом полном f64-эталоне 1024 шагов/100 мВ относительная RMS-ошибка
выхода составила 22,74%. После защиты — 0,7787%, у рабочего пути — 0,2658%.
Пиковые ошибки защищённого и рабочего путей — 0,6317 и 0,2245 В.
На 1 В оба пути недостоверны: RMS превышает 100%, сотни отказов.
Это сравнение программной математики на компьютере, не CORDIC на плате.

Полная DI 3:41 с защитой: 2611 / 15475 отказов при 100 / 250 мВ.
Отчёты: `../di_rust/report_absolute_guard_final_{100,250}.md`.
Не считать эти числа доказательством точности: метрика остановки изменена,
независимый f64-эталон проверялся только на коротких треугольниках.

## Вывод

Точное исключение само по себе не обеспечивает ускорения. В данном варианте
остались смешанные координаты и дорогие преобразования нормы. Выигрыша нет.
Следующий опыт в `../control_ports/report.md` использует непосредственно 19
управляющих координат нелинейных законов, не 29 сохранённых MNA-неизвестных.

## Повторение

Из корня проекта:

```sh
.venv/bin/python simulation/generate_rust_model.py
.venv/bin/python simulation/run_absolute_ports_reference.py
cd firmware
cargo fmt
cargo test -p orange-dsp --release --target aarch64-apple-darwin compare_full_f64_trajectories -- --ignored --nocapture
cargo build -p h7r3-runtime --bin ram-probe --release --features absolute-ports
```

Только после успешной сборки, из корня, с подключённым ST-Link:

```sh
openocd -f embedded/openocd/weact_stm32h7r3.cfg -f embedded/openocd/run_ram_probe.cfg -c run_ram_probe
```

Загрузка только в RAM, затем `reset run` заводского приложения; flash не меняется.
Для воспроизведения отрицательного опыта без дополнительного контроля портового
дефекта генератор принимает `--absolute-no-port-guard` (не штатная настройка).
