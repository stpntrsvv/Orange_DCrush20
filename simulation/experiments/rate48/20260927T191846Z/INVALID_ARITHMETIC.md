# Отрицательный запуск стенда

Сборка без fpu-roots включила CORDIC-корни вместо закреплённой арифметики P7. Промежуточные такты нельзя приписывать нужному кандидату. Полный прогон прерван, данные сохранены; после остановки выполнена отдельная проверка reset run. Повторная свежая сборка включает fpu-roots и compile_error без этого признака.
