## Текущее состояние: до трёх попыток, 2026-09-27

**Реализован `BoundedState<3,7>`: до трёх попыток на причинный блок, с ранним выходом, без поиска длины, повторного решения и временных подшагов. P7 остаётся базой.** В TDA применяется Halley с явной второй производной; остальные нелинейные блоки уточняются Newton. Это не три глобальных прохода всей модели. Аналитические стартовые оценки не меняют физические законы P7; LUT нет.

Причина прежнего срыва IC3B — ложное насыщение внутреннего полюса в начальном приближении. На ступени 1 В первая старая поправка предлагала 8,111 В на диодах при корне 0,548 В. После нормировки строк по диагонали число обусловленности проверенных матриц <=5,148; исходное 2,679e6 смешивало токовые и напряженческие строки. Новый совместный старт ОУ/диода устраняет этот перелёт. У TDA отдельно исправлен старт относительно slew-перехода.

|---|---:|---:|
| Треугольник 100 мВ | 18922 / 17244 | 19698 / 22106 |
| Треугольник 1 В | 23563 / 20471 | 26724 / 42473 |
| Шум 250 мВ | 22377 / 36341 | 26829 / 56262 |

Это реальный парный H7R3: интерполяция и два внутренних шага 96 кГц включены, фильтр/DMA/I/O ещё нет. Шум ускорился на 38,43%; среднее на двух треугольниках ухудшилось на 9,73% / 15,10%. **Бюджет 12500 CPU / 10000 DSP пока превышен.**

50 release-тестов прошли, включая проверки предела каждого блока и второй производной TDA. топологиями, причинный Class-D-порт и DMA/I/O всё ещё отдельно не квалифицированы.

## Код, данные и безопасный запуск

- `simulation/condensed_physical.py`: f64-прототип и поддержка реактивной нагрузки.
- `simulation/generate_condensed.py`: отдельный генератор нового Rust-ядра.
- `firmware/orange-dsp/src/condensed.rs`, `generated_condensed.rs`.
- `simulation/{audit_condensed_structure,validate_condensed_dc_ac,run_condensed_qualification,run_condensed_reference,run_condensed_timestep,run_condensed_multirate,analyze_condensed_hardware}.py`.
- `firmware/orange-dsp/examples/condensed_di.rs`: длинная проверка без WAV.
- Все отчёты, отрицательные версии, траектории, ELF и SHA — `architecture_decision/`.

Текущие коэффициенты **BDF2/96 кГц**, ручки 0,5, резистивная нагрузка,
фиксированные шины и затвор. Для Rust реактивная нагрузка и другие ручки ещё
не генерируются этим новым генератором. Файлы генерации вручную не менять.

```sh
export PATH=/opt/homebrew/Cellar/rustup/1.29.1/bin:$PATH
.venv/bin/python simulation/generate_condensed.py --rate 96000 --method bdf2
cd firmware
cargo fmt
cargo test -p orange-dsp --release --target aarch64-apple-darwin -- --include-ignored
cargo build -p h7r3-runtime --bin ram-probe --release --features condensed-probe
```

Только после успешной сборки, из корня Orange, проверить наличие ST-Link и:

```sh
openocd -f embedded/openocd/weact_stm32h7r3.cfg -f embedded/openocd/run_condensed_probe.cfg -c run_condensed_probe
```
