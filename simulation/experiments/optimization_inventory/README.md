# Предварительная карта сокращений, 2026-09-27

Основной результат — [документ 11](../../../docs/11%20Где%20сокращать%20вычисления.md).
Это исследование исходников, существующего ELF и сохранённых данных.
Прошивка не изменялась; новых измерений MCU и новых траекторий интегрирования нет.

Из корня проекта:

```sh
.venv/bin/python simulation/audit_optimization_opportunities.py
```

Скрипт создаёт `audit.json` и `current_elf.asm`. Дизассемблер — установленный
Rust LLVM с явным `--mcpu=cortex-m7`, чтобы инструкции FPU декодировались.
`manifest.json` фиксирует SHA-256 входных файлов, документа и результатов.
Это снимок воспроизводимости, не самостоятельная сборка контроллера.

Статистика ветвей относится к принятым состояниям полных f64-эталонов.
Она не считает промежуточные пробы Newton и не доказывает ускорения.
Статическое число инструкций включает альтернативные ветви и циклы;
оно не равно числу исполненных инструкций или тактов.

Сравнение ошибки по времени использует прежние файлы
`architecture_decision/condensed_{bdf2,trap}_*.npz` и полную MNA/6,144 МГц.
Окна около ступеней служат анализу распределения ошибки и не исключаются
из окончательного критерия. Новые кандидаты пока не измерены и не приняты.
