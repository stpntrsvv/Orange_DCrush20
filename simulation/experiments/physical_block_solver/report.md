# Первый каскадный физический решатель

Пять блоков решаются одним прямым проходом; внутри блока связи точные.
Перебраны все 120 порядков на шести ветвях fixture.

- лучший порядок: `IC3B+D4D5 → IC3A+D6D7 → IC4A → IC4B+Q1 → TDA2050`;
- худшая `error/tolerance`: 5.724320e-01;
- средняя `error/tolerance`: 9.543510e-02.

Это проверка одного каскадного прохода, а не финальная аттестация.

## Rust/H7R3

Первый перенос оставил глобальное `L⁻¹`: плотный проход 29×29, сборку
всей 14×14 матрицы, универсальные малые solve с pivoting и полное восстановление.
Это проверка формул, а не целевая архитектура.
